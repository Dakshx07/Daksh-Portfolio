# Daksh Hiran — Portfolio

Creative developer & software engineer specializing in modern web interfaces, high-performance web applications, motion design, and interactive experiences.

## 🚀 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, React 19)
- **Styling**: Vanilla CSS, Responsive Layouts
- **Animations & Graphics**: GSAP, ScrollTrigger, Lenis Smooth Scroll, Canvas 2D, WebGL
- **TypeScript**: Strict typing for project data and application structure

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Production build
npm run build
```
